# Sphene Gyre

Full-colour Python 3 neon orbital-slingshot arcade for [ElbowOS](https://x.com/ElbowOS).

Ride a copper comet around a gold sun and four drifting gravity wells.
Space slings you off the current orbit; wells recapture the bead.
Scoop orbiting shards for chain score. Dark rocks break the combo.
Left / Right (or A / D) change spin while captured. Space / W / Up slings.

## Play

```bash
pip install -r requirements.txt
python3 sphene_gyre.py --play
```

## Record a 9:16 reel

```bash
python3 sphene_gyre.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
